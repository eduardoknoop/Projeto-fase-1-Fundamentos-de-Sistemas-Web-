# Projeto PetShop - Fase 1

Sistema web estático desenvolvido em HTML puro para a disciplina de Sistemas Web.

## Funcionalidades da Página
- **Cabeçalho:** Contém o título do petshop, subtítulo e um menu de navegação em lista com âncoras para as seções da página.
- **Produtos:** Exibição detalhada de 6 produtos divididos em 3 categorias obrigatórias (Acessórios, Rações Não Perecíveis e Higiene/Limpeza), incluindo imagens ilustrativas, descrições e valores.
- **Serviços:** Apresentação dos serviços prestados (Banho e Tosa com tele-busca e Banho Simples sem tele-busca), com descrição e preços.
- **Rodapé:** Informações institucionais, dados de contato, endereço e créditos autorais do estudante.

## Tecnologias Utilizadas
- HTML5 (sem uso de CSS, Bootstrap ou JavaScript nesta fase).
